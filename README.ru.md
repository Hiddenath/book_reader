# 📖 BookHaven 3D

**Самодостаточная 3D-читалка электронных книг** — веб-приложение, которое имитирует физическую книгу в трёхмерном пространстве. Работает без сборки, Node.js и npm — только браузер и Python.

>

## ✨ Возможности

### Чтение

- 📕 **3D-разворот книги** с анимацией перелистывания страниц (CSS 3D)
- 📱 **Одностраничный режим** — для вытянутых/портретных экранов автоматически показывается только правая страница
- 🖱️ **Интерактивное перелистывание** — захват угла страницы мышью или пальцем
- 👆 **Сенсорное управление** — свайпы влево/вправо и широкие зоны тапа по краям экрана
- 🔊 **Клавиши громкости** — листание в Android WebView-обёртке (в обычном браузере их перехватывает ОС)
- ⌨️ **Навигация**: стрелки, пробел, Home/End, боковые зоны клика
- 📄 **Динамическая вёрстка** — текст разбивается на страницы под размер экрана, шрифт и отступы
- 📍 **Сохранение позиции** — при повторном открытии книга возвращается к месту, где вы остановились (по якорям текста, не по номерам страниц)

### Библиотека

- 📚 **Сетка карточек** с обложками, названием, автором и прогрессом
- ➕ **Добавление книг**: кнопка, Drag & Drop
- 📂 **Форматы**: TXT, EPUB, FB2
- 🗑️ **Удаление книг** с подтверждением
- 💾 **Хранение на сервере** — книги лежат в папке `books/`, метаданные в `meta.json`

### Закладки

- 🔖 **Добавление/удаление** закладок с превью текста
- 📑 **Боковая панель** со списком, клик — переход к месту
- 🎯 **Маркер на краю книги** — визуальный индикатор закладки

### Оглавление

- 📃 **Навигация по главам** — переход к любой главе из панели оглавления

### Настройки

- 🔤 **Размер шрифта**, межстрочный интервал, отступы
- 🎨 **5 тем**: Бумага, Сепия, Ночной, Лес, Небо
- 🌙 **Режим погружения** — клик по центру скрывает все панели

## � Управление с телефона

- **Тап по краям экрана** — правый/левый край листает вперёд/назад (на сенсорных экранах зоны автоматически шире)
- **Свайп** — смахивание влево листает вперёд, вправо — назад
- **Клавиши громкости** — в обычном браузере их перехватывает операционная система, поэтому листание работает в **Android WebView-обёртке**. Обёртка может управлять читалкой тремя способами (реализация — `js/reader.js`, `_bindVolumeKeys`):

| Способ   | Как это сделать в обёртке                                                                                                 |
| -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| JS-мост    | Вызвать`window.BookHavenNative.volumeUp()` / `.volumeDown()` (например, через `evaluateJavascript` в `onKeyDown`) |
| Событие | Отправить`window.dispatchEvent(new Event('volumeup'))` / `('volumedown')`                                                         |
| Клавиша | Переслать в WebView`keydown` с `keyCode` 175 (громче) / 174 (тише)                                                    |

## �🚀 Быстрый старт

```bash
# Запустить сервер (статику + API одним файлом)
python3 server.py

# Открыть в браузере
http://127.0.0.1:8080
```

Сервер запускает два процесса в потоках:

- **8080** — статические файлы (HTML/CSS/JS)
- **8001** — API для сохранения состояния и книг

Опции:

```bash
python3 server.py          # оба сервера
python3 server.py --static # только статика (8080)
python3 server.py --api    # только API (8001)
```

## 🔧 Как это работает

### Пагинация

Текст разбивается на страницы в браузере: скрытый измеритель считает высоту каждого абзаца при текущих настройках шрифта, затем абзацы укладываются на страницы. Каждый абзац получает стабильный идентификатор (`data-block-id`), привязанный к книге и порядковому номеру — поэтому позиция чтения не «плывёт» при изменении настроек.

### Хранение данных

Книги лежат **прямыми файлами** в `books/` — исходное имя файла сохраняется, никаких подпапок. Служебная информация (прогресс, закладки, метаданные) хранится в файле `<имя>.meta.json` рядом с книгой.

| Что                                                               | Где                                 |
| -------------------------------------------------------------------- | -------------------------------------- |
| Книги (оригиналы)                                      | `books/<имя>.fb2 / .txt / .epub`  |
| Метаданные книги (прогресс, закладки) | `books/<имя>.meta.json`           |
| Глобальные настройки                              | `localStorage` + `data/state.json` |

### API

| Метод | Путь                     | Описание                                                 |
| ---------- | ---------------------------- | ---------------------------------------------------------------- |
| `GET`    | `/books`                   | Список книг (метаданные без текста) |
| `POST`   | `/books`                   | Сохранить книгу (копирует в`books/`)    |
| `GET`    | `/books/<id>/text`         | Текст книги (FB2 парсится на лету)       |
| `GET`    | `/books/<id>/meta`         | Метаданные книги                                  |
| `POST`   | `/books/<id>/meta`         | Обновить прогресс/закладки               |
| `GET`    | `/books/<id>/cover`        | Обложка книги (из`<coverpage>` FB2)              |
| `GET`    | `/books/<id>/image/<name>` | Картинка из тела книги (`<binary>` FB2)     |
| `DELETE` | `/books/<id>`              | Удалить книгу                                        |

## 📋 Технологии

- **Frontend**: чистый ES2022 JavaScript, CSS3 Custom Properties, CSS 3D transforms
- **Backend**: Python `http.server` (без зависимостей)
- **Библиотеки**: epub.js + JSZip (скачаны в `/lib/`)
